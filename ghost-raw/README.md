# ghost-raw

Flow(Veo)에서 받은 원본 귀신 영상(mp4)을 이 폴더에 넣습니다.

- 파일 이름은 어떤 귀신인지 알 수 있게 지어 주세요. 예: `standing.mp4`, `approach.mp4`, `ceiling.mp4`
  (역할: standing, approach, crawling, peeking, crouched, suspended, ceiling, wallcrawl)
- 이 폴더의 영상은 원본 보관용이라 git에 올라가지 않습니다.
- 앱에서 쓰는 변환본은 `public/ghosts/`에 만들어집니다.
