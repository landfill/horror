# 04:44 — 출구 없음

게임이 아니라 **공포 체험**을 목표로 하는 웹앱입니다. 흑백 화면 속 끝없이 이어지는 복도 미로를 걷는 동안, 링·주온 스타일의 실사 귀신이 드물고 느리게 나타납니다. 점수, 목표, 클리어가 없습니다.

- 교차로에서 좌우로 갈라지는 무한 복도. **지나온 길은 바뀝니다** (안 보이는 곳의 복도가 열리고 닫히고, 멀리 갔다 오면 구조와 공간 테마가 새로 정해짐)
- 같은 공간 테마라도 복도마다 소품·조명·얼룩·문 상태가 다르고, 귀신이 없어도 **사물이 조용히 바뀌어 있음** (돌아보면 문이 열려 있고, TV가 켜져 있음)
- 귀신은 AI(구글 Flow / Veo)로 만든 실사 영상을 3D 공간에 합성
- 공간 음향(HRTF)과 콘크리트 복도 잔향, 정적을 활용한 소리 연출

## 실행

```bash
npm install
npm run dev      # http://localhost:4444
npm run build    # dist/ 로 빌드
```

`main` 브랜치에 푸시하면 Vercel이 자동으로 배포합니다.

## 조작

화면의 조작 안내와 버튼은 영어로 표시됩니다.

| PC | 화면 표기 | 동작 |
|---|---|---|
| ↑ ↓ / W S | MOVE | 전진 · 후진 |
| ← → | TURN | 제자리 방향 전환 |
| A D | STRAFE | 옆걸음 |
| 마우스 | LOOK | 시점 (화면 클릭 시 고정, 안 되면 드래그) |
| ESC | PAUSE | 일시정지 (첫 화면에서는 동작 안 함) |

모바일은 왼쪽 드래그로 이동(LEFT DRAG MOVE), 오른쪽 드래그로 시점을 돌립니다(RIGHT DRAG LOOK). 헤드폰 착용을 권장합니다.

## 첫 화면

카드 없이, 뒤에서 실제 복도가 비쳐 보이는 화면입니다. 피·붉은색·큰 글리치는 쓰지 않고 잔잔한 흑백으로 불안만 남깁니다.

- **언어**: 조작 요소(ENTER, SUBTITLES, PAUSE, RESUME, VOLUME, 조작 안내)는 영어만 씁니다. 나머지 문구는 영어·일본어·한국어를 섞되, 핵심 안내 3개(게임이 아닌 공포 체험 / 출구가 없음 / 헤드폰 권장)는 세 언어로 모두 적어 하나만 읽을 수 있어도 알 수 있게 합니다. 각 문장에 `lang` 속성을 달아 한자가 언어에 맞는 글꼴로 나옵니다.
- **글꼴** (Google Fonts, `display=swap`): 영어 Cormorant Garamond · 일본어 Shippori Mincho · 한국어 Nanum Myeongjo · 조작 요소 IBM Plex Mono. 못 불러오면 시스템 명조(AppleMyungjo, Hiragino Mincho, Batang 등)로 이어집니다.
- **연출**: 시선이 숨 쉬듯 아주 느리게 흔들리고 형광등이 깜빡입니다. 04:44 시계가 가끔 한순간 04:45가 됐다 돌아오고, 아래 한 줄은 복도에서 겪게 될 일들을 세 언어로 바꿔 가며 예고합니다. 두 번째 방문부터는 "여기 와 본 적 있죠" 류의 문장으로 시작합니다(브라우저 저장소를 못 쓰면 생략). 탭을 떠나 있으면 탭 제목이 바뀝니다.
- `prefers-reduced-motion`이 켜져 있으면 움직이는 연출을 끕니다.
- 문구는 `index.html`, 바뀌는 문장과 시계 연출은 `src/ui/TitleScreen.ts`에 있습니다.

## 공간 변주와 이상 현상

**복도 변주** (`src/world/CorridorBuilder.ts`, `src/world/Props.ts`): 복도와 교차로는 만들어질 때 한 번만 모양이 정해집니다. 안개 너머나 시야 밖에서 만들어지므로 보는 동안 바뀌지 않습니다.

- 벽·바닥·천장 재질의 밝기와 무늬 위치, 얼룩, 빠진 천장 타일
- 형광등 1~3개의 위치와 상태 (흐림, 꺼짐, 한쪽이 빠져 비스듬히 매달림)
- 테마별 소품의 개수·위치·상태: 교실 문(가끔 살짝 열림)·사물함·게시판·의자 / 404호 철문·부적·실내화·택배 상자 / 벽장·족자·방석 / 비디오 진열장·흩어진 테이프·TV·우물 / 안내판·줄지어 붙은 실종 전단지·기둥·벤치
- 교차로의 막다른 벽에 달린 어디로도 이어지지 않는 문, 모퉁이의 사물, 문틀 문짝의 방향과 각도
- 소품은 벽에 붙여 걷는 길과 문틀 통로를 막지 않고, 공유 재질만 써서 메모리가 늘지 않습니다.

**이상 현상** (`src/world/Anomalies.ts`): 귀신에만 기대지 않고 사물과 공간이 주는 불안입니다. 플레이어가 한 번 본 자리가 **지금 시야 밖일 때만** 조용히 바뀌고, 귀신이 보이는 동안과 직후에는 일어나지 않습니다. 평소에는 45~90초에 한 번꼴입니다.

| 이상 현상 | 내용 |
|---|---|
| 문 | 지나온 문이나 벽장이 살짝 열려 칠흑이 보임 (처음부터 열려 있던 문은 닫혀 있음). 가끔 멀리서 작게 끼익 |
| 의자 | 복도를 보던 의자가 벽을 보고 있음 |
| TV | 꺼져 있던 브라운관이 켜져 있음 |
| 전단지 | 줄지어 붙은 같은 실종 전단지 중 하나만, 사진 속 사람이 돌아서 있음 |
| 실내화 | 404호 문 앞에 없던 실내화가 가지런히 놓여 있음 |
| 같은 사물 | 앞 교차로 모퉁이에서 본 사물이 다음 교차로 같은 자리에도 있음 |
| 형광등 | 등 뒤의 형광등이 먼 것부터 하나씩 꺼짐 |

빈도와 간격은 `src/world/Anomalies.ts` 위쪽 상수로 조절합니다.

## 귀신

등 뒤의 따라오는 귀신 하나와 앞쪽 귀신 하나가 동시에 나올 수 있습니다. 플레이어가 보고 있는 곳에서는 갑자기 생기지 않고, 정면이라면 안개 너머에서 모습을 드러냅니다.

| 귀신 | 동작 | 영상 |
|---|---|---|
| 다가오기 (`approach`) | 복도 끝에서 아주 천천히 다가옴. 코앞까지 오면 마주침 | 실사 |
| 기어오기 (`crawling`) | 바닥을 기어옴 | 실사 |
| 천장 (`ceiling`) | 천장에 거꾸로 매달림. 아래에서 올려다보면 마주침, 그냥 지나치면 등 뒤로 내려와 따라옴 | 실사 |
| 벽 기어오르기 (`wallcrawl`) | 보는 동안 벽을 타고 천장까지 기어오르고, 시선을 돌린 사이 벽을 따라 다가와 있음. 천장에 닿으면 매달려 멈췄다가 다시 보면 사라져 있음 | 실사 |
| 서 있기 (`standing`) | 지켜보다가 다시 보면 없어져 있음 | 실사 |
| 따라오는 귀신 | 지나온 길을 따라옴. 돌아볼 때마다 더 가까이 있음 | 실사 (`standing`) |
| 엿보기 (`peeking`) | 교차로 문틀 옆에서 내다보다 숨음 | 실사 |
| 웅크림 (`crouched`) | 벽 아래 웅크려 고개를 듦 | 실사 |
| 공중에 뜸 (`suspended`) | 허공에 떠 있음 | 임시 영상 (출현 안 함) |

천장·기어오기·다가오기는 다른 귀신보다 3배 자주 나옵니다. 출현 확률과 쉬는 시간은 `src/world/Haunts.ts` 위쪽 상수로 조절합니다.

## 귀신 영상 추가하기

1. Flow(https://flow.google.com/)에서 초록 배경, 고정 카메라 영상을 만듭니다. 귀신 종류별로 필요한 동작은 [docs/ghost-footage.md](docs/ghost-footage.md)를 참고하세요.
2. 원본을 `ghost-raw/`에 넣습니다 (git에 올라가지 않음).
3. 변환합니다. 결과는 `public/ghosts/<이름>.mp4` (위 절반 색상, 아래 절반 투명도 마스크).

   ```bash
   scripts/make-ghost-clip.sh ghost-raw/standing.mp4 standing --cover 90x90 --height 1280 --fps 24
   ```

   | 옵션 | 용도 |
   |---|---|
   | `--cover 90x90` | 오른쪽 아래 AI 생성 표시 제거 (Flow 영상은 항상) |
   | `--lo N` / `--hi N` | 배경 지우는 기준. 몸이 비치면 `--lo`를 올리고, 배경이 남으면 `--hi`를 낮춤 (기본 25 / 70) |
   | `--loopfade S` | 영상 안에서 귀신이 이동해 반복 때 튀는 경우, 끝 S초를 처음과 겹쳐 이어 붙임 |
   | `--pingpong` | 한 방향 동작(고개 들기 등)을 정방향 + 역방향으로 왕복 |
   | `--reverse` | 역재생본도 함께 생성 |

   ffmpeg가 필요합니다.
4. `src/ghost/clips.ts`의 `GHOST_CLIPS`에 항목을 추가합니다. 실제 영상은 같은 역할의 임시 영상보다 우선 쓰입니다.

   | 필드 | 의미 |
   |---|---|
   | `aspect` | 변환 스크립트가 출력하는 값 |
   | `frameHeightM` | 프레임 세로 전체가 공간에서 몇 m인지 |
   | `footV` | 발이 프레임 아래에서 몇 % 높이에 있는지 |
   | `hangV` | 천장에 매달린 영상일 때, 천장에 닿는 지점(프레임 위에서부터 비율) |
   | `roles` | 이 영상을 쓸 귀신 종류 |
   | `stepFps` | 동작을 뚝뚝 끊는 프레임레이트 (12 권장) |

## 확인용 주소

| 주소 | 용도 |
|---|---|
| `/?debug=ghosts` | 모든 복도(시작 지점 포함)에 귀신 배치 |
| `/?debug=ghosts&haunt=ceiling` | 한 종류만 강제 (`approach`, `floorcrawl`, `ceiling`, `wallcrawl`, `watcher`, `peek`, `crouched`, `suspended`, `follower`) |
| `/?mutate=fast` | 지나온 길이 바뀌는 것을 자주 시도 |
| `/?debug=anomaly` | 사물 이상 현상을 3~5초마다 시도 (콘솔에 종류 출력) |
