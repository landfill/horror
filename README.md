# 04:44 — 출구 없음

게임이 아니라 **공포 체험**을 목표로 하는 웹앱입니다. 흑백 화면 속 끝없이 이어지는 복도 미로를 걷는 동안, 링·주온 스타일의 실사 귀신이 드물고 느리게 나타납니다. 점수, 목표, 클리어가 없습니다.

- 교차로에서 좌우로 갈라지는 무한 복도. **지나온 길은 바뀝니다** (안 보이는 곳의 복도가 열리고 닫히고, 멀리 갔다 오면 구조와 공간 테마가 새로 정해짐)
- 같은 공간 테마라도 복도마다 소품·조명·얼룩·문 상태가 다르고, 귀신이 없어도 **사물이 조용히 바뀌어 있음** (돌아보면 문이 열려 있고, TV가 켜져 있음)
- 귀신은 AI(구글 Flow / Veo)로 만든 실사 영상을 3D 공간에 합성
- 공간 음향(HRTF)과 콘크리트 복도 잔향, 정적을 활용한 소리 연출

## 실행

```bash
npm install
npm run dev      # http://localhost:4444
npm run build    # dist/ 로 빌드
npm test         # 조명·스트리밍·귀신 영상 준비 상태 회귀 검사
```

`main` 브랜치에 푸시하면 Vercel이 자동으로 배포합니다.

## 조작

화면의 조작 안내와 버튼은 영어로 표시됩니다.

| PC | 화면 표기 | 동작 |
|---|---|---|
| ↑ ↓ / W S | MOVE | 전진 · 후진 |
| ← → | TURN | 제자리 방향 전환 |
| A D | STRAFE | 옆걸음 |
| 마우스 | LOOK | 시점 (화면 클릭 시 고정, 안 되면 드래그) |
| ESC | PAUSE | 일시정지 (첫 화면에서는 동작 안 함) |

모바일은 왼쪽 드래그로 이동(LEFT DRAG MOVE), 오른쪽 드래그로 시점을 돌립니다(RIGHT DRAG LOOK). 헤드폰 착용을 권장합니다.

- 조이스틱은 **처음 닿은 자리가 기준**이라 엄지가 가운데를 정확히 누르지 않아도 됩니다. 기준점 근처(반경의 18%)는 멈춤이고, 앞·뒤로 ±15° 안쪽으로 밀면 옆걸음 없이 똑바로 걷습니다.
- 시작 버튼을 누르면 시선이 복도 방향으로 맞춰집니다 (첫 화면의 흔들림이 남아 비스듬히 걷지 않게).

## 첫 화면

카드 없이, 뒤에서 실제 복도가 비쳐 보이는 화면입니다. 피·붉은색·큰 글리치는 쓰지 않고 잔잔한 흑백으로 불안만 남깁니다.

- **언어**: 조작 요소(ENTER, SUBTITLES, PAUSE, RESUME, VOLUME, 조작 안내)는 영어만 씁니다. 나머지 문구는 영어·일본어·한국어를 섞되, 핵심 안내 3개(게임이 아닌 공포 체험 / 출구가 없음 / 헤드폰 권장)는 세 언어로 모두 적어 하나만 읽을 수 있어도 알 수 있게 합니다. 각 문장에 `lang` 속성을 달아 한자가 언어에 맞는 글꼴로 나옵니다.
- **글꼴** (Google Fonts, `display=swap`): 영어 Cormorant Garamond · 일본어 Shippori Mincho · 한국어 Nanum Myeongjo · 조작 요소 IBM Plex Mono. 못 불러오면 시스템 명조(AppleMyungjo, Hiragino Mincho, Batang 등)로 이어집니다.
- **연출**: 시선이 숨 쉬듯 아주 느리게 흔들리고 형광등이 깜빡입니다. 04:44 시계가 가끔 한순간 04:45가 됐다 돌아오고, 아래 한 줄은 복도에서 겪게 될 일들을 세 언어로 바꿔 가며 예고합니다. 두 번째 방문부터는 "여기 와 본 적 있죠" 류의 문장으로 시작합니다(브라우저 저장소를 못 쓰면 생략). 탭을 떠나 있으면 탭 제목이 바뀝니다.
- `prefers-reduced-motion`이 켜져 있으면 움직이는 연출을 끕니다.
- 문구는 `index.html`, 바뀌는 문장과 시계 연출은 `src/ui/TitleScreen.ts`에 있습니다.

## 공간 변주와 이상 현상

**복도 변주** (`src/world/CorridorBuilder.ts`, `src/world/Props.ts`): 복도와 교차로는 만들어질 때 한 번만 모양이 정해집니다. 안개 너머나 시야 밖에서 만들어지므로 보는 동안 바뀌지 않습니다.

- 벽·바닥·천장 재질의 밝기와 무늬 위치, 얼룩, 빠진 천장 타일
- **구간 밝기**: 복도·교차로 하나를 한 구간으로 보고, 만들 때 먼저 밝음/어두움을 정합니다. 너무 어두우면 오히려 덜 무서우므로 **밝음 65 : 어두움 35**이고, 어두운 구간 중 약 1/5만 완전히 깜깜합니다. 40장 묶음(밝음 26 · 어두움 11 · 깜깜함 3)을 섞어 차례로 뽑아서 짧게 걸어도 비율이 지켜집니다.
- 형광등의 개수·위치·상태: 밝은 복도는 2~3개(거의 다 환함), 어두운 복도는 1~2개(흐림·꺼짐 위주). 가끔 한쪽이 빠져 비스듬히 매달림
- 테마별 소품의 개수·위치·상태
  - 학교: 교실 문(가끔 살짝 열림)·사물함·게시판·의자(가끔 쓰러짐)·소화기
  - 404호 아파트: 철문·부적·실내화·택배 상자·우산·우편함(칸마다 404호)·쓰레기봉투
  - 다다미 여관: 벽장·족자·방석·천장에 매단 종이 등·벽을 보고 앉은 인형
  - 비디오 대여점: 진열장·흩어진 테이프·TV·우물·진열장 위 영화 포스터·반납 카트
  - 지하철 통로: 안내판·줄지어 붙은 실종 전단지·기둥·벤치·쓰레기통·소화기
  - 여러 공간에 걸쳐: 벽의 손자국, 벽(문) 속으로 걸어 들어간 듯 끊긴 젖은 맨발 자국
- **전단지·포스터**에는 제공된 기존 에셋 사진을 사용합니다. `public/posters/corridor-woman.png`는 전달받은 두 번째 PNG를 변경 없이 보관한 파일입니다. 표시할 때 얼굴 부분을 잘라 쓰며, 얼굴을 새로 그리거나 다른 인물로 바꾸지 않습니다. 낡은 전단지 양식은 유지합니다.
- **지나칠 때의 표정** (`PosterReactions.ts`): 3.5m 안으로 걸어 들어오면 현재 화면에 보이고 벽에 가리지 않은 포스터 중 가까운 한 장이 40% 확률로 반응합니다. 눈 깜빡임은 0.4초, 입꼬리 움직임은 약 2초이며 원래 표정으로 돌아옵니다. 한 번에 한 장만 반응하고 다음 반응까지 8~14초 쉽니다. 같은 포스터의 재추첨은 5m 밖으로 나갔다 돌아와야 가능합니다. 응시 시간이나 조도 조건은 없습니다.
- **지하철 안내판**은 같은 뜻의 영어·일본어·한국어 문구가 몇 초마다 번갈아 나옵니다. 글씨는 판 크기에 맞춰 줄어들어 잘리지 않습니다.
- 교차로의 막다른 벽에 달린 어디로도 이어지지 않는 문, 모퉁이의 사물, 문틀 문짝의 방향과 각도
- 소품은 벽에 붙여 걷는 길과 문틀 통로를 막지 않고, 공유 재질만 써서 메모리가 늘지 않습니다.

**이상 현상** (`src/world/Anomalies.ts`): 귀신에만 기대지 않고 사물과 공간이 주는 불안입니다. 문은 바라보는 중에도 천천히 움직입니다. 의자·TV·실내화·발자국처럼 순간적으로 바뀌는 사물은 시야 밖에서만 변화하며, 일반 이상 현상의 간격은 45~90초입니다.

**문 열림은 별도 간격**으로 처음 6~10초 후부터, 이후 12~22초마다 시도합니다. 한 번 시야에 들어온 1.8~12m 내의 문 중 벽에 가리지 않은 가까운 문을 고릅니다. 대상이 없으면 2초 뒤 다시 시도합니다. 귀신이나 다른 사건이 진행 중이면 시작을 미루므로 실제 간격은 길어질 수 있습니다. 여닫이문은 같은 문짝이 경첩 기준으로 2.8초 동안 천천히 회전하고, 미닫이 벽장도 같은 시간으로 이동합니다. 경첩 소리는 움직임 전체에 걸쳐 이어집니다.

| 이상 현상 | 내용 |
|---|---|
| 문 | 가까운 문·벽장이 2.8초에 걸쳐 끼이익 열림. 처음부터 열린 문이 천천히 닫히기도 함 |
| 의자 | 복도를 보던 의자가 벽을 보고 있음 |
| TV | 꺼져 있던 브라운관이 켜져 있음 |
| 전단지 | 줄지어 붙은 같은 실종 전단지 중 하나만, 사진 속 사람이 돌아서 있음 |
| 실내화 | 404호 문이 열린 뒤, 문을 향하던 실내화가 복도를 향함 |
| 인형 | 여관 벽을 보고 앉아 있던 인형이 복도 쪽을 보고 있음 |
| 같은 사물 | 앞 교차로 모퉁이에서 본 사물이 다음 교차로 같은 자리에도 있음 |
| 형광등 | 등 뒤의 형광등이 먼 것부터 하나씩 꺼짐 |
| 404호 사건 | 문이 천천히 열리며 문틈 어둠 속 두 눈이 드러남 → 문이 다 열린 뒤 최소 14초 후 시야 밖에서 실내화가 복도를 향함 |
| 젖은 발자국 | 문으로 들어간 자국 옆에 밖으로 나온 한 쌍이 생김 → 최소 16초 뒤 시야 밖에서 한 쌍이 더 이어짐 |

404호 사건은 아파트 복도에서, 발자국 사건은 아파트·학교 복도에서 나타납니다. 첫 변화에는 기존 시야 판정을 사용하며, 응시 시간·조도 조건은 추가하지 않습니다. 두 번째 변화에는 재관찰 조건이 없고, 최소 간격이 지난 뒤 사물 전체가 시야 밖이고 3.5m 이상 떨어졌을 때 진행합니다. 귀신이 나타난 동안과 직후에는 후속 단계를 미루며, 26m 이상 멀어지거나 구간이 해제되면 남은 단계를 취소합니다. 이미 바뀐 상태는 구간이 남아 있는 동안 유지됩니다.

404호 문이 열리는 동안 경첩 소리, 첫 발자국이 추가될 때 젖은 발소리가 납니다. 후속 변화는 조용합니다. 같은 문에는 독립적인 문·실내화 이상 현상을 중복 적용하지 않습니다. 발자국은 공유 평면 세 장과 캐시된 텍스처 한 장을 사용하며, 사건 도중 새 모델이나 광원을 만들지 않습니다. 문은 움직이는 사물만 매 프레임 갱신하고, 구간 해제 시 갱신 대상에서도 제거합니다.

빈도와 간격은 `src/world/Anomalies.ts` 위쪽 상수로 조절합니다.

404호 사건의 문틈에는 얼굴·몸 없이 희미한 두 눈만 있습니다. 문이 열리는 후반부에 서서히 드러나고, 문짝이나 벽에 가리면 보이지 않습니다. 문틈을 빗각으로 볼 때 두 눈이 보이며, 정면이나 경첩 쪽에서는 문짝에 가려질 수 있습니다. 눈에는 별도 조명·영상·반복 애니메이션을 사용하지 않고 공유 지오메트리 메시 두 개만 추가합니다. 문마다 사용하는 페이드 재질은 해당 구간을 해제할 때 함께 해제합니다.

실내화는 둥근 밑창, 어두운 안창과 열린 뒤꿈치, 발등을 덮는 곡면으로 만듭니다. 문 옆으로 85cm 떨어뜨려 문이 열리는 경로와 겹치지 않게 했습니다. 확대된 발자국 평면은 사건용 한 쌍이 0.65×1.1m, 정적 세 걸음이 0.77×1.54m이며, 기존보다 약 40% 큽니다. 커진 자국끼리 겹치거나 벽 밖으로 나가지 않도록 배치와 시야 밖 안전 영역도 함께 조정했습니다.

## 귀신

등 뒤의 따라오는 귀신 하나와 앞쪽 귀신 하나가 동시에 나올 수 있습니다. 플레이어가 보고 있는 곳에서는 갑자기 생기지 않고, 정면이라면 안개 너머에서 모습을 드러냅니다.

| 귀신 | 동작 | 영상 |
|---|---|---|
| 다가오기 (`approach`) | 복도 끝에서 아주 천천히 다가옴. 코앞까지 오면 마주침 | 실사 |
| 기어오기 (`crawling`) | 바닥을 기어옴 | 실사 |
| 천장 (`ceiling`) | 천장에 거꾸로 매달림. 아래에서 올려다보면 마주침, 그냥 지나치면 등 뒤로 내려와 따라옴 | 실사 |
| 벽 기어오르기 (`wallcrawl`) | 보는 동안 벽을 타고 천장까지 기어오르고, 시선을 돌린 사이 벽을 따라 다가와 있음. 천장에 닿으면 매달려 멈췄다가 다시 보면 사라져 있음 | 실사 |
| 서 있기 (`standing`) | 지켜보다가 다시 보면 없어져 있음 | 실사 |
| 따라오는 귀신 | 지나온 길을 따라옴. 돌아볼 때마다 더 가까이 있음 | 실사 (`standing`) |
| 엿보기 (`peeking`) | 교차로 문틀 옆에서 내다보다 숨음 | 실사 |
| 웅크림 (`crouched`) | 벽 아래 웅크려 고개를 듦 | 실사 |
| 공중에 뜸 (`suspended`) | 허공에 떠 있음 | 임시 영상 (출현 안 함) |

복도 귀신을 고르는 비중은 다가오기 8, 천장 5, 기어오기 5, 나머지 1입니다. 공간마다 다르지만 **천장+기어오기가 복도 귀신의 절반쯤**(약 52%), 다가오기가 약 40%입니다. 출현 확률과 쉬는 시간은 `src/world/Haunts.ts` 위쪽 상수로 조절합니다.

- **앞쪽 우선**: 귀신은 플레이어가 바라보는 쪽, 벽에 가리지 않은 자리(앞 복도·앞 교차로)를 먼저 고릅니다. 옆 복도에 먼저 자리 잡은 귀신은 아무도 못 본 채면 앞쪽 자리가 생길 때 그리로 옮깁니다.
- **출현 보장**: 귀신을 못 본 채 복도를 3개째 지나면 쉬는 시간을 무시하고, 이미 끝난 귀신도 다시 배치해 앞쪽에서 나오게 합니다. 4번째 복도에서는 등 뒤 추적자도 바로 부릅니다 (`GUARANTEE_EVERY = 4`).
- **멀리서 들리는 목소리**: 귀신이 자리를 잡고 나면 그 귀신의 목소리가 작게 납니다. "꺼거걱"은 5~9초마다, 키득거림·흐느낌은 자주 나면 익숙해지므로 평균 약 25초에 한 번만 납니다. 목소리는 영상 속 인물의 성별·나이에 맞춘 **키득거리는 얕은 웃음**, **흐느낌**, 주온 가야코 같은 **목 막힌 "꺼거걱" 소리** 세 가지입니다(크게 웃거나 통곡하지 않음). 천장·벽·바닥을 기는 귀신은 "꺼거걱" 소리를 내고, 마주치는 순간에는 꼭 이 소리를 냅니다. "꺼거걱"은 녹음 없이 `src/audio/GhostCroak.ts`에서 합성합니다(성대가 느리게 탁탁 닫히는 맥박이 모음 울림을 때리는 방식). 거리 감쇠를 약하게 해서 같은 복도 어디서든 들리고, 옆 복도에서도 희미하게 들립니다. 추적자는 발소리만 내다가 처음 눈이 마주칠 때 목소리를 냅니다.
- **목소리 파일**: 실제 사람 녹음(`public/voices/`, m4a, 파일당 25KB 이하)을 씁니다. 귀신이 배치될 때 그 귀신의 파일만 받고, 받기 전이나 실패하면 합성 목소리(`src/audio/GhostVoice.ts`)로 대신합니다. 같은 파일이 연달아 나오지 않고, 높이를 ±8% 안에서 바꾸며, 가끔 거꾸로 재생합니다. 출처와 라이선스는 `public/voices/README.md`에 있습니다.

## 귀신 영상 추가하기

1. Flow(https://flow.google.com/)에서 초록 배경, 고정 카메라 영상을 만듭니다. 귀신 종류별로 필요한 동작은 [docs/ghost-footage.md](docs/ghost-footage.md)를 참고하세요.
2. 원본을 `ghost-raw/`에 넣습니다 (git에 올라가지 않음).
3. 변환합니다. 결과는 `public/ghosts/<이름>.mp4` (위 절반 색상, 아래 절반 투명도 마스크).

   ```bash
   scripts/make-ghost-clip.sh ghost-raw/standing.mp4 standing --cover 90x90 --height 1280 --fps 24
   ```

   | 옵션 | 용도 |
   |---|---|
   | `--cover 90x90` | 오른쪽 아래 AI 생성 표시 제거 (Flow 영상은 항상) |
   | `--lo N` / `--hi N` | 배경 지우는 기준. 몸이 비치면 `--lo`를 올리고, 배경이 남으면 `--hi`를 낮춤 (기본 25 / 70) |
   | `--loopfade S` | 영상 안에서 귀신이 이동해 반복 때 튀는 경우, 끝 S초를 처음과 겹쳐 이어 붙임 |
   | `--pingpong` | 한 방향 동작(고개 들기 등)을 정방향 + 역방향으로 왕복 |
   | `--reverse` | 역재생본도 함께 생성 |

   ffmpeg가 필요합니다.
4. `src/ghost/clips.ts`의 `GHOST_CLIPS`에 항목을 추가합니다. 실제 영상은 같은 역할의 임시 영상보다 우선 쓰입니다.

   | 필드 | 의미 |
   |---|---|
   | `aspect` | 변환 스크립트가 출력하는 값 |
   | `frameHeightM` | 프레임 세로 전체가 공간에서 몇 m인지 |
   | `footV` | 발이 프레임 아래에서 몇 % 높이에 있는지 |
   | `hangV` | 천장에 매달린 영상일 때, 천장에 닿는 지점(프레임 위에서부터 비율) |
   | `roles` | 이 영상을 쓸 귀신 종류 |
   | `stepFps` | 동작을 뚝뚝 끊는 프레임레이트 (12 권장) |

## 확인용 주소

| 주소 | 용도 |
|---|---|
| `/?debug=ghosts` | 모든 복도(시작 지점 포함)에 귀신 배치 |
| `/?debug=ghosts&haunt=ceiling` | 한 종류만 강제 (`approach`, `floorcrawl`, `ceiling`, `wallcrawl`, `watcher`, `peek`, `crouched`, `suspended`, `follower`) |
| `/?mutate=fast` | 지나온 길이 바뀌는 것을 자주 시도 |
| `/?debug=anomaly` | 사물 이상 현상을 3~5초마다 시도 (콘솔에 종류 출력) |
| `/?debug=anomaly&story=room404&zone=apt404` | 404호 사건만 빠르게 확인. 각 복도 왼쪽 입구에서 약 7.8m 지점에 배치 |
| `/?debug=anomaly&story=footsteps&zone=school` | 발자국 사건만 빠르게 확인 (`zone=apt404`도 가능) |
| `/?debug=posters&zone=subway` | 첫 복도 왼쪽에 같은 얼굴의 포스터 3장 배치. 걸어 지나가며 무작위 반응 확인 (`zone=video`도 가능) |
| `/?zone=subway` | 모든 곳을 한 공간 테마로 (`school`, `apt404`, `tatami`, `video`, `subway`). `debug` 옵션과 함께 쓸 수 있음 |

`debug` 값이 있으면 개발자 도구에서 `window.__app`(앱), `window.__ghostClips`(영상 풀)에 접근할 수 있습니다.

사건 확인 모드에서 문은 바라보는 중에도 열립니다. 실내화·발자국에는 시야 밖 조건을 유지하고, 후속 단계 간격만 최대 2초로 줄입니다. 문 움직임 자체는 실제와 같은 2.8초입니다. `story` 옵션은 `debug=anomaly`일 때만 적용되며, 지정 사건은 귀신 대기에 막히지 않습니다.

## 화면 가시성

- 주변광과 근거리 잔광으로 문틀·사물·귀신의 윤곽을 읽을 수 있게 합니다. 먼 복도의 안개 밀도는 유지합니다.
- 비네팅은 후처리에서 한 번만 적용합니다. CSS의 중복 비네팅·흑백 필터를 제거하고 필름 그레인을 줄여 머리카락·얼굴·바닥 무늬가 뭉개지지 않게 했습니다.
- 귀신 영상의 색상/투명도 합성 텍스처는 `NoColorSpace`로 읽습니다. 마스크는 그대로 두고 프리멀티플라이를 해제한 RGB만 선형 색상으로 변환합니다.
- 첫 영상 프레임을 표시하기 전에는 귀신을 봤다고 판정하거나 마주침을 일으키지 않습니다. 12초 동안 준비되지 않으면 출현 자리를 반환하고 나중에 다시 시도합니다. 미디어 로딩 오류에는 기존 대체 모델을 사용합니다.

## 모바일 성능

끝없이 생성·해제되는 복도를 휴대폰에서도 끊김 없이 돌리기 위한 원칙입니다. 새 소품·연출을 넣을 때도 지켜 주세요.

- **조명**: 형광등용 PointLight는 항상 12개(`LightPool`, 카메라 잔광 별도). 꺼진 기구는 슬롯을 차지하지 않습니다. 개수가 바뀌면 모든 재질의 셰이더가 다시 컴파일되어 화면이 멈칫합니다. 밝기 조절은 기구의 세기(`base`)로만 하고, 그림자는 쓰지 않습니다.
- **재질·텍스처**: `Textures.ts`의 캐시된 Lambert 재질과 캔버스 텍스처만 씁니다. 텍스처는 처음 한 번만 그리고(256×256 이하, 2의 거듭제곱), 매 프레임 다시 그리지 않습니다. 블러는 `ctx.filter` 대신 겹쳐 그리기로 냅니다(iOS Safari).
- **포스터 표정**: 원본 PNG 한 장을 받은 뒤 5프레임(기본·반쯤 감은 눈·감은 눈·약한 입꼬리 변형·입꼬리 변형)을 한 번만 준비합니다. 기본 표정은 원본 픽셀 그대로이며 다른 프레임은 눈·입 주변 픽셀만 작게 이동합니다. 한 포스터의 재질만 교체하고 공유 재질의 텍스처를 바꾸지 않으므로 벽 전체가 동시에 움직이지 않습니다. 머리카락·얼굴 나머지 부분·종이는 고정돼 있습니다. 기존 전단지 뒷면 이상 현상이 발생하면 표정 반응을 취소해 뒷면 상태를 보존합니다.
- **지오메트리**: 상자·원기둥·평면 소품은 크기 1짜리 공유 지오메트리를 `scale`로 키워 씁니다(`Props.ts`의 `boxMesh`, `plane`). 구간을 해제할 때 `userData.shared`가 붙은 지오메트리는 지우지 않습니다. 둥근 것은 면 수를 적게(원기둥 8각, 덩어리 20면체).
- **안내판 언어 바뀜**: 문구 묶음마다 재질 하나를 함께 쓰고, 미리 그린 텍스처 3장 중에서 `map`만 바꿉니다.
- **귀신 영상**: 자주 나오는 영상(걸어오기 2종·천장·기어오기)만 처음부터 받고, 나머지는 메타데이터만 받아 두었다가 쓰려고 할 때나 게임이 조용할 때 하나씩 받습니다. 임시 영상은 쓸 때만 만듭니다. iOS 재생 허락은 내려받기 시작한 뒤의 첫 터치에서 받습니다.
- **매 프레임 할당 없음**: 이동·시선 계산과 조명 정렬은 재사용 객체를 씁니다.
- **탭 숨김**: 다른 탭으로 가거나 화면이 꺼지면 영상 재생과 그리기를 멈춥니다.
- **일시정지**: 타이틀을 제외한 정지 화면은 마지막 프레임을 유지합니다. 리사이즈·WebGL 컨텍스트 복구 때는 다시 그립니다.
- **월드 스트리밍**: 가장 가까운 교차로가 바뀔 때만 생성/해제 범위를 검사합니다. 같은 구간에서 정지하거나 움직일 때는 반복 탐색하지 않습니다.
