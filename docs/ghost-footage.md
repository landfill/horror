# 귀신 실사 영상 촬영·교체 가이드

## 촬영 사양
- **배경**: 그린스크린 권장(머리카락·검은 옷이 있으므로 검은 배경보다 키잉이 깨끗함). 배경과 배우 사이 2m 이상 띄워 초록 반사를 줄임.
- **카메라**: 삼각대 고정, 렌즈 높이 약 1.6m(관람자 눈높이), 줌·흔들림 없음. 세로 프레임이면 좋음.
- **조명**: 위에서 내려오는 차가운 조명 하나(형광등 느낌) + 배경만 따로 고르게. 얼굴 정면 조명 금지.
- **노출/셔터**: 30fps 이상, 셔터 1/60 이하로 모션블러 최소화(키잉 품질).
- **배우·분장**: 긴 검은 가발(얼굴 가림), 흰 소복/원피스, 창백한 피부. 머리카락 사이로 눈 하나만 보이게.

## 필요한 클립 (각 5~15초, 루프 가능하게)
| role (clips.ts) | 동작 |
|---|---|
| `standing` | 고개를 옆으로 꺾고 거의 정지. 가끔 아주 미세하게 움찔 |
| `approach` | **카메라에서 멀어지듯 뒤로 걷기** → 역재생 시 다가오는 부자연스러운 걸음 (`--reverse`) |
| `crawling` | 바닥에서 카메라 쪽으로 기어오기. 관절을 어색하게 |
| `peeking` | 프레임 옆에서 상체와 머리만 기울여 내다보기 |
| `crouched` | 웅크린 채 고개만 천천히 듦 |
| `suspended` | 발끝이 늘어진 채 미세하게 흔들림(와이어 또는 받침대 위) |
| `ceiling` | **바닥에 등을 대고 누운 배우를 바로 위(천장)에서 촬영.** 카메라를 올려다보듯 고개를 천천히 기울임. 머리카락은 얼굴 쪽으로 늘어지게 정리. 머리가 프레임 위쪽 |
| `wallcrawl` | **바닥을 기는 배우를 바로 위에서 촬영.** 머리가 프레임 위쪽, 프레임 위 방향으로 관절을 어색하게 꺾으며 기어감. 앱에서 벽에 눕혀 붙임 |

## 귀신 행동 (영상과 별개로 코드가 처리)
- **천장**: 바로 아래에서 올려다보면 마주침. 올려다보지 않고 지나치면 등 뒤로 내려와 따라옴.
- **벽 기어가기**: 쳐다보면 그 자리에 멈춤(영상도 정지), 시선을 돌리면 다가옴.
- **추적자**: 지나온 길을 따라옴. 돌아볼 때마다 9m → 5m → 2.6m로 가까워져 있고, 마지막엔 마주침.
- **모퉁이**: 교차로 문틀 옆에서 내다보다 눈이 마주치면 옆 복도로 숨음.
- 한 번에 하나만 나타나고, 귀신 자리는 두 개(등 뒤 추적자 하나 + 앞쪽 귀신 하나), 하나가 끝나면 3~6초 쉼.

## 변환과 등록
```bash
scripts/make-ghost-clip.sh raw/approach.mov approach --key green --reverse
```
출력된 `aspect` 값을 `src/ghost/clips.ts`에 항목으로 추가합니다.
- `frameHeightM`: 프레임 세로 전체가 공간에서 몇 m인지 (배우 키 + 위 여백)
- `footV`: 발이 프레임 아래에서 몇 % 높이에 있는지
- `stepFps`: 동작을 뚝뚝 끊을 프레임레이트 (8~15 권장, 0 = 원본)

실제 영상이 등록되면 같은 role의 임시 영상(`placeholder: true`)보다 우선 사용됩니다. 모든 role이 채워지면 `test_placeholder` 항목과 파일을 지우면 됩니다.

## 확인
`http://localhost:4444/?debug=ghosts` — 모든 구간(시작 구간 포함)에 귀신이 나옵니다.
종류 하나만 보려면 `&haunt=ceiling` (approach, watcher, ceiling, wallcrawl, floorcrawl, peek, suspended, crouched, follower).
